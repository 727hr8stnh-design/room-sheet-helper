# 客室仕込みヘルパー

iPhone Safari向けの静的Webアプリ（PWA）です。

## できること
- アサイン表をカメラ撮影／画像選択
- OCRで部屋データをベストエフォート抽出
- 部屋番号検索
- 大人・子供・合計人数
- シーツ数自動計算（1名=1、2名=2、3名=3、4名以上=4）
- バッシングBOX判定（夕食あり=1個、朝食のみ/素泊まり=不要）
- その日のBOX総数
- 氷あり／なし記録
- 氷なし部屋の補充リストと件数
- 備考・特記事項を強調表示
- 読み取り後の手動修正
- データを端末内(localStorage)に保存

## iPhoneでホーム画面アプリ化
このフォルダをHTTPSで公開してください（GitHub Pages / Netlify / Cloudflare Pages等）。
SafariでURLを開き、共有 →「ホーム画面に追加」。

## 注意
OCRは表のレイアウトや写真品質で誤認識します。人数・食事区分・備考は作業前に必ず確認してください。
特にアレルギー等の重要事項はOCRだけに依存しない運用が必要です。
